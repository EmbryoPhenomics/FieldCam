# FieldCam

## A submersible field camera and sensor instrument

![image](https://github.com/EmbryoPhenomics/FieldCam/blob/main/assets/fieldcam_render.jpg)

FieldCam is a versatile, waterproof imaging and sensing instrument, powered by consumer AA batteries and capable of long term timelapse imaging out in the field. Some of the key specifications of this instrument are as follows:

| Waterproof enclosure | Acrylic tube with aluminium end caps rated to 130m depth |
| Battery | 17.1 Ah AA battery pack (~24 hrs continuous video recording). Capacity for additional 22.8 Ah AA battery pack (~30 hrs). Low power mode is > 10 years with continuous system and sensor monitoring (5 second resolution) |
| Processors | STM32 L4 microcontroller for system control and low power standby. Raspberry Pi Zero 2W for video and image capture, 32gb and 1Tb SD cards for storage respectively |
| Camera sensor | CMOS 12-megapixel (Sony IMX708) |
| Video resolution | 1080p50fps maximum. Resolution and framerate can be configured using built-in app |
| Focus | Phase Detection Autofocus (PDAF) or manual adjustable focus. Range 5cm to > 2m. | 
| Camera parameters | Exposure (Auto or manual), analogue gain and auto-white balance modes can all be configured via Web App |
| Lighting | Built-in adjustable LEDs (x2) with up to 170 lm each |
| Sensors | Temperature and light built-in. Pressure, salinity, pH and O2 available with additional sensor pack | 
| Configuration | Setup via Web App using smartphone or laptop, connected to the instrument’s wifi hotspot. Web App enables live streaming and config of camera sensor, viewing of system status and programming of experimental schedule.  All data, including video and sensor logs can be downloaded via network file sharing when in setup mode | 
| Dimensions | 70 mm x 195 mm |
